2026-10-15 변경 내역

9장짜리 첫 버전을 화면 모양 그대로 옮기고, 아래 항목을 고치거나 추가했다. 장 순서를 화면 ID 순서로 바꿨다.
  • 1. 로그인 · 비밀번호 변경 (S-01, S-02 · 레이아웃 없음) — "관리자 아이디" → 관리자·직원 공용, 직원 잠금 규칙 확인 필요
  • 2. 공통 레이아웃 (S-02~S-18 공통) — 역할별 메뉴표에 STAFF·MANAGER 열 추가, 활동 로그 "초안" → SUPER_ADMIN 전용 확정, 헤더 설명 "관리자·직원"
  • 4. 목록 틀 - 회원 목록 예시 (S-05 · 목록 화면 공통) — "휴대폰은 가운데 마스킹" → 마스킹 여부 확인 필요 (샘플 값은 그대로 둠)
  • 5. 계좌 상세 (S-08 · 탭 전환 가능) — 탭 3개 내용을 모두 담음. 상태 이력: "시스템 · 계좌 개설" 줄 삭제, 안내 문구를 D-10 기준으로 (팀원2 상의 예정)
  • 6. 계좌 상세 - 동결 모달 (S-08, M-01) — "계좌 상태 이력 1건" 삭제 → 상태 변경 + admin_log 1건 (팀원2 상의 예정)
  • 7. 거래 관리 (S-09 · 탭 전환 가능) — 새로 추가. 탭 2개(전체 거래 / 이체내역) + 직원이 검색 전에 보는 화면. 검색 칸·컬럼은 명세서 2.7, FR-ADM-TRX-002 기준
  • 9. 대출 상세 - 심사 모달 (S-13, M-02) — 새로 추가. STAFF 접수 → MANAGER 승인 (D-04), 상태값은 팀원3 협의 필요
  • 10. 이상거래 탐지 상세 (S-16 · 구현 범위 미정) — MANAGER는 조회만 (처리 버튼·입력 칸 숨김) 한 줄 추가 — 재검토 필요 (01-기획서 11장)
  • 12. 계정 관리 (S-19, S-20, M-03) — 새로 추가. SUPER_ADMIN이 관리자·직원 계정을 만든다 (회원가입 아님). 직원 사번은 자동 생성(ACT-005). 관리자/직원 탭 전환 가능. 모든 장의 사이드바 메뉴 이름 "관리자 계정" → "계정 관리", 2장 역할별 메뉴표도 같이 고침

1. 로그인 · 비밀번호 변경 (S-01, S-02 · 레이아웃 없음)

S-01 로그인 (/admin/login) · 사이드바, 헤더 없는 단독 화면

Bank Admin 로그인

오류 메시지 자리: "아이디 또는 비밀번호가 올바르지 않습니다" / "사용할 수 없는 계정입니다"

고객 계정으로는 로그인할 수 없다. 관리자 전용(/admin/login). 직원은 /employee/login으로 따로 로그인한다 (D-02). 5회 연속 실패하면 계정 잠금 (직원 잠금 규칙은 확인 필요). 로그인에 성공하면 대시보드로 이동하고, 임시 비밀번호 상태면 비밀번호 변경 화면으로 이동한다.

S-02 비밀번호 변경 (/admin/password) · 임시 비밀번호면 강제 이동

비밀번호 변경

임시 비밀번호로 로그인했습니다. 비밀번호를 변경해야 다른 메뉴를 이용할 수 있습니다.
비밀번호 규칙 안내 자리

임시 비밀번호 상태에서는 사이드바와 헤더 메뉴를 숨겨 다른 화면으로 못 가게 한다. 변경이 끝나면 임시 여부를 해제하고 대시보드로 이동.

이 창을 닫으면 임시 비밀번호를 다시 볼 수 없습니다.

저장할 때 비밀번호는 BCrypt 해시로, temp_pw_yn = Y. admin_log 1건 (ADMIN_CREATE / EMPLOYEE_CREATE, 안). 임시 비밀번호는 로그에 남기지 않는다. 화면에 보여 주는 방식은 모의 프로젝트용 단순화 (01-기획서 5.1).

생성 뒤 흐름

  1. 확인을 누르면 계정 목록(S-19)으로 돌아가고 새 계정이 맨 위에 보인다 (임시 비밀번호 Y)
  2. 새 계정으로 첫 로그인 → 비밀번호 변경 강제 (관리자: S-02 / 직원: 팀원1 쪽 강제 이동)
  3. 변경하면 temp_pw_yn = N

직원은 FUNC-ADM-ACT-005 (03-기능명세서 2.15). 사번은 자동 생성. 확인 필요: 마지막 사번 조회 메서드 위치 (팀원1 EmployeeRepository 또는 관리자 파트).
